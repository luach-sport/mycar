# MyCar — עד הטיפה האחרונה

אפליקציית אנדרואיד שמחשבת כמה תעלה נסיעה בדלק, ושומרת יומן נסיעות ותדלוקים. עובדת גם בלי אינטרנט.

## הורדה

**[הורדת האפליקציה (mycar.apk)](https://github.com/luach-sport/mycar/releases/latest/download/mycar.apk)**

הקישור תמיד מוביל לגרסה האחרונה.

### התקנה בטלפון
1. פותחים את הקישור בטלפון ומורידים את הקובץ.
2. פותחים את הקובץ שירד. בפעם הראשונה הטלפון יבקש לאשר "התקנה ממקור לא ידוע". מאשרים.
3. מתקינים ופותחים, ומגדירים את הרכב (סוג, צריכה בעיר ובין-עירוני, נפח מיכל).

**עדכון:** מורידים שוב מאותו קישור ומתקינים מעל. הנתונים נשמרים.

## מה יש באפליקציה
- **מחשבון נסיעה:** מוצא ויעד (כל יישוב בארץ, מיקום GPS, או כתובת מדויקת כשיש אינטרנט), ק״מ, ליטרים ועלות בשקלים, משוקלל לפי נסיעה עירונית ובין-עירונית. הלוך-חזור, חלוקה בין נוסעים, וניווט בווייז.
- **יומן נסיעות:** כל נסיעה שנשמרה, לפי חודש, עם סינון עבודה / פרטי וייצוא לאקסל.
- **יומן תדלוקים:** סכום, מחיר לליטר, ליטרים וקילומטרז׳. כמה ק״מ נסעת מכל תדלוק, הצריכה האמיתית (ממיכל מלא למיכל מלא) ועלות לקילומטר.
- **נתונים:** הוצאה חודשית, צריכה לפי תדלוק, נסיעות עבודה מול פרטיות.
- **כמה רכבים**, מחיר דלק אוטומטי (המחיר המפוקח), ידני או לפי התדלוק האחרון, ותוספת שירות מלא.
- **תזכורות:** טסט, ביטוח וטיפול לפי קילומטרז׳.
- **מצב בהיר / כהה / לפי המכשיר**, גיבוי ושחזור, ופנייה / הצעת ייעול שמגיעה במייל.

## בלי אינטרנט
כל החישובים והנתונים שמורים בטלפון. באפליקציה יש את רשימת היישובים של הלמ״ס עם מיקומים, מרחקי כבישים אמיתיים בין כ-120 ערים מרכזיות, ומחיר הדלק. כשיש חיבור, האפליקציה מחשבת מסלול מדויק ושומרת אותו, ומורידה לבד נתונים חדשים מהתיקייה `www/data` בריפו.

## איך זה בנוי
- `www/`: האפליקציה (HTML, CSS ו-JavaScript בלי תלויות). `www/data/`: הנתונים לשימוש בלי אינטרנט.
- `scripts/fetch-data.mjs`: מעדכן מרחקי כבישים (OSRM) ומחיר דלק (משרד האנרגיה).
- `android-res/`, `tools/`: אייקונים ומסך פתיחה, וכלים שמייצרים אותם.
- `.github/workflows/build.yml`: כל דחיפה ל-main בונה APK חתום ומפרסמת אותו ב-Releases.
- `.github/workflows/update-data.yml`: פעם בחודש מעדכן את מחיר הדלק והנתונים.
- `signing/release.jks`: מפתח החתימה, מוצפן. הסיסמה שמורה בסוד `MYCAR_KEY_PASS` של הריפו.
